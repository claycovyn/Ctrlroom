# Vendored: @openctrl/mcp-kit (Cloud parts)

`manifest.ts` and `cloud.ts` are copied from `packages/mcp-kit/src` in the OPENCTRL repository
(github.com/claycovyn/openctrl). Don't edit them here: change the kit there, then copy the files back over. Ctrl Room has
no MCP server yet, so the MCP parts of the kit (and the `@modelcontextprotocol/sdk` dependency) aren't copied. Once the
kit is published to npm, replace this folder with `npm install @openctrl/mcp-kit`. This folder stays MIT (`LICENSE`).
