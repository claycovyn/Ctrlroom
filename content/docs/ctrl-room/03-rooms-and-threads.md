# Rooms, messages and threads

## Rooms

- **Text rooms** are for chat. Each can have a topic shown in the header.
- **Announcement rooms** (megaphone icon) let only mods and up start new posts. Everyone can still reply in threads.
- **Voice rooms** open a call bar when you walk in. They also have text chat.

Admins add rooms in **Settings → Rooms**: give it a name, choose Text or Voice, and optionally make it announcements only. Deleting a room deletes all its messages.

## Send a message

- **Enter** sends. **Shift+Enter** adds a new line.
- Type **@** and a few letters to mention someone. Pick a name with the arrow keys and Enter or Tab.
- Links become clickable. Wrap text in backticks for `code`, or three backticks for a code block.
- Messages can be up to 4,000 characters.

## React, edit, delete

Hover a message to see its tools:

- **React** with 👍 ❤️ 😂 🔥 👀 ✅. Click a reaction again to remove yours.
- **Edit** your own messages. Enter saves, Esc cancels. Edited messages show "(edited)".
- **Delete** your own messages. Mods can delete messages from people ranked below them. Deleted messages show as "Message removed".
- **Pin to board** saves the message to the room board.

## Threads

Choose **Reply in thread** to open a thread next to the room. Threads are one level deep: replies to a reply stay in the same thread. The original message shows how many replies it has.

When a thread is settled, the person who started it (or a mod) can choose **Close with an outcome** and write what was decided. The outcome shows under the original message in the room, and can be pinned to the room board as a **decision**. Closed threads can be reopened.
