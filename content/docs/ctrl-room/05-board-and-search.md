# Room board and search

## The room board

Every room has a board for things that shouldn't get lost in chat. Open it with the board button in the room header. Items are one of four kinds: **decision**, **link**, **doc** or **note**.

Things get on the board three ways:

- **Pin to board** on any message.
- **Close a thread with an outcome** and keep "Pin it to the room board" checked.
- **Add a decision, link or doc** directly from the board.

Filter the board by kind. The person who added an item, or a mod, can remove it. **View message** jumps to the message an item came from.

## Search

Use the search button in a room's header to search every message in the community, from all time. There is no history limit and search is free.

- Put a phrase in quotes for an exact match: `"launch date"`.
- Put a minus sign before a word to leave it out: `meetup -online`.

Click a result to open its room. A result from a thread takes you to the message that started the thread.
